\# RST Changelog



All notable changes to the Redheaded Stepchild Tech platform will be documented in this file.



Versioning follows \*\*MAJOR.MINOR.PATCH\*\*:

\- \*\*MAJOR\*\* — New platform phase (Donation System → Swap‑Meet → Stories → Enterprise)

\- \*\*MINOR\*\* — New features or significant improvements

\- \*\*PATCH\*\* — Bug fixes, UI tweaks, small adjustments



\---

\- Footer links: Contact Us, Report a Bug

\- Version badge: `v1.0.0`
